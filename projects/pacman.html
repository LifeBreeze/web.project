팩맨 게임

C 언어로 만든 콘솔 팩맨입니다. 무작위로 만들어지는 미로에서 악마(X)를 피해 먹이(.)를 모두 먹으면 이깁니다. 아래에서 원본 규칙 그대로 바로 플레이할 수 있습니다.

시기
2023년 11월 ~ 12월
언어
C (Windows 콘솔)
본인 역할
게임 로직 및 UI 구현
기준 버전
pacmanreal (3).cpp

바로 플레이하기

난이도 - Score 0 Lives - 먹은 먹이 -

게임 화면을 한 번 누른 뒤 WASD 또는 방향키로 움직입니다. 원본처럼 한 번 움직일 때마다 악마도 한 번 움직입니다. R 다시 하기(누를 때마다 새로운 맵 구조로 바뀝니다), Q 메뉴로.

구현한 것

매번 다른 미로

안쪽 칸의 20%를 무작위 벽으로 채우고, 주변이 비어 있는 칸에만 벽을 20~30개 더 세워 길이 막히지 않게 했습니다.

난이도 3단계

구조체 Difficulty 하나로 목숨, 악마 수, 벽 수, 먹이 수, 악마 이동 여부를 한꺼번에 바꿉니다.

어려움: 시야 제한

팩맨에서 맨해튼 거리 7칸 안만 보이고 나머지는 어둡게 가려, 악마가 어디서 나올지 모르게 했습니다.

움직이는 악마

보통부터는 악마가 턴마다 절반 확률로 2칸씩 점프합니다. 벽, 먹이, 다른 악마가 있는 칸은 피합니다.

콘솔 색상

SetConsoleTextAttribute로 팩맨은 노랑, 악마는 빨강, 벽은 파랑으로 찍어 화면을 구분했습니다.

점수와 상태

점수, 남은 목숨, 전체 먹이 수, 먹은 먹이 수를 매 턴 화면 아래에 보여 줍니다.

핵심 코드

struct Difficulty {
    int lives;
    int demonMoveEnabled;
    int wallCount;
    int demonadd;
    int randomfood;
    int visibilityRadius;
};

case 3:
    lives = 1;
    gameStart((struct Difficulty){.lives = lives, .demonMoveEnabled = 1,
        .wallCount = 10, .demonadd = 20, .randomfood = 25, .visibilityRadius = 7});

디버그 해결 경험

벽이 길을 막아 갇히는 판

문제
무작위로 벽을 세우다 보니 팩맨이나 먹이가 벽에 둘러싸여 갈 수 없는 판이 자주 나왔습니다.
원인
벽을 놓을 칸을 고를 때 주변 칸을 확인하지 않아 벽끼리 붙으면서 통로가 막혔습니다.
해결
상하좌우 네 칸에 벽이 없을 때만 벽을 추가하도록 조건을 넣었습니다. 웹 버전에서는 모든 먹이에 닿을 수 있는지 탐색으로 확인하고, 아니면 판을 다시 만듭니다.

글자 색이 번지는 화면

문제
팩맨과 악마에 색을 넣자 그 뒤에 찍히는 벽과 먹이까지 같은 색으로 바뀌었습니다.
원인
SetConsoleTextAttribute로 바꾼 색은 다시 바꾸기 전까지 콘솔에 계속 남습니다.
해결
색 있는 글자를 하나 찍을 때마다 바로 기본색(7)으로 되돌리도록 했습니다.

남은 먹이 수가 화면에 안 나옴

문제
전체 먹이 수를 화면 아래에 보여 주려 했지만 draw()에서 값을 알 수 없었습니다.
원인
먹이 수는 placeFood() 안의 지역 변수라서 함수 밖으로 전달되지 않았습니다.
해결
placeFood(difficulty, &totalFood)처럼 포인터로 넘겨 값을 받아 오고, draw()에 인자로 전달했습니다.

먹이를 다 먹어도 끝나지 않음

문제
먹이를 모두 먹어도 승리 화면이 나오지 않고 게임이 계속됐습니다.
원인
남은 먹이 수 food를 0으로 시작해 줄이기만 해서, 0이 되는 순간이 오지 않았습니다.
해결
웹으로 옮기며 남은 먹이 수를 전체 먹이 수로 시작하게 고쳐 승리 판정이 동작하게 했습니다.

한 번 부딪히면 악마가 멈춤

문제
악마와 한 번 부딪힌 뒤로는 모든 악마가 그 자리에서 움직이지 않았습니다.
원인
부딪힘 표시 isEaten을 1로 바꾼 뒤 다시 0으로 돌려놓지 않았습니다.
해결
웹 버전에서는 부딪힌 뒤 3턴만 멈췄다가 다시 움직이게 했습니다.

배운 점과 성취

핵심으로 배운 것

  • 2차원 배열 하나로 게임 판 전체(벽, 먹이, 캐릭터)를 표현하고 갱신하는 방법
  • 구조체로 난이도 설정을 묶어 함수 하나에 넘기는 설계
  • 포인터로 함수 밖의 값을 바꾸는 방법(call by reference)
  • rand()로 무작위 맵을 만들 때 생기는 예외 상황을 조건으로 막는 법

성취

  • 버전 8개를 거치며 판 크기, 난이도 3단계, 시야 제한까지 기능을 단계적으로 늘렸습니다.
  • C언어를 배우고 처음으로 만든 게임입니다.
  • 1학년 2학기 기말고사 과제로 제출했고, 이 사이트에서 원본 규칙과 난이도 그대로 체험할 수 있습니다.
