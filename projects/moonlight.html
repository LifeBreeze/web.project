달빛 카페 웹사이트

해방촌 언덕의 오래된 인쇄소 1층에 해가 진 뒤에만 문을 여는 가상의 카페 '달빛'을 만들고, 그 카페의 홈페이지를 여섯 쪽으로 지었습니다. 서버 없이 HTML, CSS, 자바스크립트만 썼고, 휴대폰부터 넓은 모니터까지 화면 폭에 맞춰 배치가 바뀝니다. 웹프로그래밍 개인 과제로 만들었습니다.

직접 둘러보기

새 창으로 열기 ↗

창 안에서 메뉴를 누르고 스크롤해 실제 사이트처럼 둘러볼 수 있습니다. '휴대폰 크기'를 누르면 같은 사이트가 좁은 화면에서 어떻게 바뀌는지 볼 수 있습니다.

카페와 메뉴, 주소와 전화번호는 모두 가상입니다. 공간과 메뉴 그림은 도면을 바탕으로 만든 3D 이미지입니다.

구현한 것

반응형 배치

700 · 900 · 1100px에서 배치를 바꾸고, clamp()와 grid, subgrid로 글과 사진의 높이를 맞췄습니다.

오늘 밤의 달

날짜로 달의 나이를 계산해 첫 화면의 달 그림에 오늘 밤의 그림자를 그리고, 초승달 · 보름달 같은 이름을 붙입니다.

지금 영업 중인지

요일과 시각으로 영업 여부를 계산해 머리글에 '영업 중', '오늘 휴무'를 띄우고, 영업시간 표에서 오늘 칸을 표시합니다.

메뉴판 데이터

메뉴 서른일곱 가지를 자바스크립트 배열 하나에 담고, 분류 탭과 메뉴 카드를 그 데이터로 그립니다.

평면도에서 자리 찾기

공간 페이지의 평면도는 SVG로 그렸고, 번호를 누르면 도면에서 그 자리를 찾아 표시합니다.

첫 화면 사진 넘기기

공간 사진과 시그니처 메뉴 사진 열한 장이 6초마다, 또는 사진 왼쪽 · 오른쪽을 누르면 한 장씩 바뀝니다.

핵심 코드

// 날짜로 달의 나이(일)를 구하고, 얼마나 밝은지 계산한다
function moonPhase(date) {
  const days = (date.getTime() - KNOWN_NEW_MOON) / 86400000;
  const age = ((days % SYNODIC) + SYNODIC) % SYNODIC;   // 0 ~ 29.53일
  const angle = (age / SYNODIC) * Math.PI * 2;
  const lit = (1 - Math.cos(angle)) / 2;                // 0 = 삭, 1 = 보름

  return { age, angle, lit, waxing: angle <= Math.PI };
}

디버그 해결 경험

고친 CSS가 화면에 안 보임

문제
스타일을 고치고 깃허브 페이지에 올렸는데 예전 모양이 그대로 보였습니다.
원인
브라우저가 예전에 받아 둔 CSS · JS 파일을 그대로 다시 썼습니다.
해결
파일 주소 뒤에 ?v=날짜-번호를 붙이고, 고칠 때마다 번호를 올려 새 파일을 받게 했습니다.

주소 글자만 갑자기 커짐

문제
찾아오시는 길에서 주소와 연락처 묶음을 새로 만들었더니 주소 글자가 제목보다 크게 나왔습니다.
원인
새로 붙인 클래스 이름이 홈의 큰 주소 글씨 .visit-address와 같았습니다.
해결
이름을 .visit-contact로 바꿔 두 스타일이 섞이지 않게 했습니다.

사진을 빠르게 넘기면 순서가 꼬임

문제
첫 화면 사진을 빠르게 여러 번 넘기면, 잠시 뒤 지나간 사진이 다시 나타났습니다.
원인
아직 불러오지 못한 사진마다 '다 불러오면 보여 주기'가 걸려 있다가 늦게 실행됐습니다.
해결
마지막으로 고른 사진 번호를 기억해 두고, 그 사진일 때만 보여 주도록 했습니다.

깃허브 페이지 첫 화면이 이력서

문제
공개 주소로 들어가면 카페가 아니라 예전 이력서가 먼저 열렸습니다.
원인
깃허브 페이지는 저장소 맨 위의 index.html을 첫 화면으로 엽니다.
해결
이력서를 resume.html로 옮기고, 맨 위 index.html이 카페로 넘어가게 했습니다.

배운 점과 성취

핵심으로 배운 것

  • 미디어 쿼리와 grid로 한 페이지를 휴대폰 · 태블릿 · 모니터에 맞게 다시 배치하는 법
  • 메뉴 같은 내용을 데이터 배열로 분리해 HTML을 자바스크립트로 그리는 법
  • 날짜와 시각 계산(Date)으로 페이지가 오늘에 맞게 바뀌게 하는 법
  • 사용자 입장에서 빈 곳과 균형을 보고 배치를 여러 번 고쳐 나가는 법

성취

  • 서버 없이 여섯 쪽짜리 카페 사이트를 완성해 깃허브 페이지로 배포했습니다.
  • 달의 모양, 영업 상태, 오늘 요일처럼 들어올 때마다 달라지는 정보를 넣었습니다.
  • 이 페이지 안에서 넓은 화면과 휴대폰 크기로 사이트를 바로 둘러볼 수 있습니다.
