몬스터 디펜스

pygame으로 만든 세로 슈팅 게임입니다. 마법사가 마법 미사일로 위에서 내려오는 몬스터를 막습니다. 몬스터에 부딪히거나 6마리를 놓치면 끝납니다. 원본 그림과 효과음을 그대로 써서 웹에서 플레이할 수 있게 옮겼습니다.

시기
2023년 6월
언어
Python 3 · pygame
본인 역할
게임 로직 및 UI 구현
배포
PyInstaller 실행 파일(.exe)

바로 플레이하기

게임 화면을 누르거나 Space로 시작합니다. 방향키로 움직이고 Space로 미사일을 쏩니다. 원본처럼 키를 누를 때마다 속도가 5씩 붙습니다.

구현한 것

스프라이트 클래스

pygame.sprite.Sprite를 상속해 마법사, 미사일, 몬스터를 각각 클래스로 나누고 그룹으로 관리했습니다.

점점 어려워지는 난이도

잡은 몬스터 수에 따라 한 번에 나오는 수와 내려오는 속도가 함께 올라갑니다. 웹 체험판은 처음엔 천천히 1마리씩 내려오다가 잡을수록 점점 빨라지고 많아지게 맞췄습니다.

충돌 판정

미사일과 몬스터, 마법사와 몬스터의 사각형 충돌을 매 프레임 확인해 폭발과 게임 오버를 처리합니다.

몬스터 6종

assets/virus 폴더의 그림 중 하나를 무작위로 골라 몬스터마다 다른 모습으로 나오게 했습니다.

효과음과 배경음악

발사음, 폭발음 3종, 게임 오버 효과음과 반복 배경음악을 넣었습니다.

실행 파일 배포

resource_path()로 리소스 경로를 처리해 PyInstaller로 만든 .exe에서도 그림과 소리가 열리게 했습니다.

게임에 쓴 그림

디버그 해결 경험

실행 파일에서 그림이 안 열림

문제
파이참에서는 잘 되던 게임이 PyInstaller로 만든 .exe에서는 그림과 소리를 찾지 못하고 꺼졌습니다.
원인
.exe는 실행할 때 리소스를 임시 폴더(sys._MEIPASS)에 풀어 두기 때문에 상대 경로가 맞지 않았습니다.
해결
resource_path() 함수를 만들어 .exe일 때는 임시 폴더, 아닐 때는 현재 폴더를 기준으로 경로를 만들었습니다.

키를 떼도 미끄러지는 마법사

문제
방향키를 눌렀다 떼도 마법사가 계속 한쪽으로 움직였습니다.
원인
키를 누를 때(KEYDOWN) 속도만 더하고, 뗄 때 속도를 되돌리는 처리가 없었습니다.
해결
KEYUP 이벤트에서 좌우 키면 dx = 0, 위아래 키면 dy = 0으로 멈추게 했습니다.

화면 밖으로 나가는 마법사

문제
방향키를 계속 누르면 마법사가 화면 밖으로 사라졌습니다.
원인
이동한 뒤 위치가 화면 범위를 넘는지 확인하지 않았습니다.
해결
이동 후 화면을 벗어나면 이번 이동만큼 되돌리는 처리를 넣었습니다.

갈수록 느려지는 게임

문제
오래 플레이할수록 미사일과 몬스터가 쌓여 화면이 버벅였습니다.
원인
화면 밖으로 나간 미사일과 몬스터 스프라이트가 그룹에 계속 남아 있었습니다.
해결
화면을 벗어나면 kill()로 그룹에서 지우고, 놓친 몬스터는 그때 세도록 했습니다.

배운 점과 성취

핵심으로 배운 것

  • pygame.sprite.Sprite 상속과 스프라이트 그룹으로 객체를 관리하는 방법
  • 이벤트 처리 → 로직 → 그리기로 나뉘는 게임 루프 구조와 FPS 고정
  • 사각형 충돌 판정과, 점수에 따라 난이도를 올리는 공식 설계
  • PyInstaller로 배포할 때의 리소스 경로 처리

성취

  • 그림, 효과음, 배경음악까지 갖춘 게임을 .exe로 만들어 다른 컴퓨터에서도 실행되게 했습니다.
  • 잡은 수에 따라 몬스터 수와 속도가 자동으로 올라가는 난이도 곡선을 만들었습니다.
  • 1학년 1학기 기말고사 과제로 제출했고, 이 사이트에서 원본 조작과 충돌 판정 그대로 체험할 수 있습니다.
