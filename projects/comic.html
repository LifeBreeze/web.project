만화방 만들기

tkinter로 만든 3층짜리 "스마트 복합 만화 갤러리 룸"입니다. 층 사진을 직접 눌러 계단으로 오르내리고, 층마다 다른 장르의 만화를 찾아 열어 볼 수 있습니다. 기말 과제로 만들었습니다.

시기
2026년 6월
언어
Python 3 · tkinter
본인 역할
프로그래밍 개발 및 UI
구성
1층 웹툰 · 2층 일본만화 · 3층 카툰

직접 돌아다녀 보기

현재 위치 : 1층 웹툰

사진 속 계단(점선 영역)을 누르면 층을 옮기고, 그 밖의 곳을 누르면 그 층의 만화를 골라 볼 수 있습니다. 원본 프로그램의 클릭 판정 좌표를 그대로 썼습니다.

층 사진 출처: 서울 이태원의 만화방 ‘그래픽(GRAPHIC)’ 실제 내부 사진. 만화 표지 그림의 저작권은 각 작품의 작가와 출판사에 있으며, 과제 시연용으로만 사용했습니다.

구현한 것

클릭 위치로 동작 나누기

bind("<Button-1>")로 배경 클릭 좌표를 받아 계단 영역이면 층 이동 창을, 아니면 만화 찾기 창을 띄웁니다.

층마다 다른 계단

1층은 2·3층 중 고르고, 2층은 왼쪽 계단으로 3층, 오른쪽 계단으로 1층, 3층은 2층으로 내려갑니다.

팝업 대화상자

Toplevel 창으로 이동할 층을 묻고, 버튼 하나로 배경을 바꾸며 창을 닫습니다.

만화 열기와 상태 표시

파일 대화상자로 만화 그림을 열고, 경로에서 파일 이름만 잘라 위쪽 상태창에 보여 줍니다.

확대와 축소

메뉴에서 1~4배를 입력받아 zoom()과 subsample()로 만화 그림 크기를 바꿉니다.

메뉴 바 구성

층 이동, 장르별 도서 목록, 확대, 축소, 종료를 위쪽 메뉴 바에 모았습니다.

디버그 해결 경험

불러온 그림이 바로 사라짐

문제
층을 바꾸거나 만화를 열면 그림이 잠깐 보였다가 빈 화면이 됐습니다.
원인
함수 안에서 만든 PhotoImage가 함수가 끝나면 메모리에서 지워져 라벨이 그릴 그림을 잃었습니다.
해결
bgLabel.image = photo처럼 라벨에 그림을 붙잡아 두어 지워지지 않게 했습니다.

층을 옮겨도 이전 만화가 남음

문제
2층에서 연 만화가 1층으로 내려가도 그대로 떠 있었습니다.
원인
배경만 바꾸고 만화 라벨은 그대로 두었습니다.
해결
배경을 바꾸는 chg_bg()에서 cLabel.place_forget()으로 만화를 숨기고 현재 만화 경로도 비웠습니다.

상태창에 경로가 길게 나옴

문제
"현재 보고 있는 만화"에 C:/Users/... 같은 전체 경로가 그대로 찍혔습니다.
원인
파일 대화상자가 돌려주는 값은 파일 이름이 아니라 전체 경로였습니다.
해결
split("/")[-1]로 경로를 잘라 마지막 파일 이름만 보여 주게 했습니다.

만화 없이 확대를 누르면 오류

문제
만화를 열기 전에 확대나 축소를 누르면 프로그램이 오류로 멈췄습니다.
원인
열린 만화 경로가 비어 있는데 그 경로로 그림을 다시 읽으려 했습니다.
해결
경로가 비어 있으면 "먼저 만화를 불러와주세요" 안내 창을 띄우고 함수를 끝내도록 했습니다.

배운 점과 성취

핵심으로 배운 것

  • tkinter 이벤트 바인딩으로 클릭 좌표를 받아 영역별로 다른 동작을 하게 만드는 법
  • Toplevel 팝업과 메뉴 바로 사용자 흐름을 구성하는 법
  • 이미지 객체의 수명(참조) 관리와 zoom()·subsample()로 크기를 바꾸는 법
  • 기능을 함수 단위로 나눠(배경, 만화, 팝업, 클릭) 코드를 정리하는 법

성취

  • 실제 만화방(이태원 그래픽) 사진으로 3층짜리 공간을 만들고, 계단을 눌러 오가게 했습니다.
  • 층마다 다른 장르의 만화를 찾아 열고, 확대·축소까지 되는 갤러리를 완성했습니다.
  • 기말 과제로 제출했고, 이 사이트에서 원본 클릭 판정 그대로 체험할 수 있습니다.
